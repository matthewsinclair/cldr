## Fix outline

devbin-cc's three parts for devbin#0326, as devbin-vc agreed them on 2026-11-06, say what Cldr does. Their key names are what devbin builds next, and devbin-cc sends any change. None of it works until a devbin release carrying #0326 is vendored (`bin/devbin upgrade`), so Cldr prepares, and releases nothing that depends on it before then.

- **Declare the binary to the core**, in `bin/.devbin/config.yaml`, and drop `formula.bin` (`:53-54`), which the link set replaces. The tool's name is `project.name`, so the manifest is `<root>/.cldr-install`; `commands.build` already runs `cargo build --release --locked`.

  ```yaml
  install:
    prefix: ~/opt/cldr
    links:
      cldr: target/release/cldr
    files:
      config:
        path: config.toml
        from: examples/config.toml
  ```

- **The version line.** `cldr --version` prints the manifest's `# line:` when `<the binary's own directory>/../.cldr-install` holds one naming cldr; else `option_env!("DEVBIN_VERSION_LINE")`, which `bin/devbin build` stamps as `cldr <version> (dev, <sha12>[+dirty])`; else `cldr <version> (unknown, unknown)`. devbin's contract will spell these lines once, and devbin-cc sends them word for word with devbin's stamp unit: copy them, and write none of our own. No `build.rs`. A plain `cargo build` prints `(unknown, unknown)`.
- **The formula's one form.** In `packaging/homebrew/cldr.rb:31-37` the install body becomes `@@INSTALL@@`, then `pkgshare.install_symlink libexec/"config.toml"`, so that `README.md:19`'s `$(brew --prefix)/share/cldr/config.toml` still holds, then `verify_signature`, whose `libexec/"bin/cldr"` (`:28`) holds as it is. `@@FINISH@@` and the hand layout go, and the header comment (`:1-5`) follows. T8's caveats name `bin/devbin use`, run in Cldr's checkout, for a maintainer with a dev or opt tree; the template has no `caveats` today. The archive needs no change: `bin/.devbin/cmd/macos:183-186` already roots it at the install root, with `bin/cldr`, and `config.toml` from `examples/config.toml`.
- **Not Cldr's.** No `cldr use`, no `cldr install` and no `cldr version` (see Decision). The switch, the publish, the manifest and the shadow check are devbin's.
